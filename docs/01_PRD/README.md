# 01_PRD/

Qué se construye y para quién. El PRD y sus documentos de soporte — reglas de negocio, usuarios, historias, alcance y métricas de éxito.

| Documento | Contenido |
|---|---|
| [`ProductRequirements.md`](ProductRequirements.md) | El PRD en sí — documento de nivel superior, sintetiza el resto de esta carpeta y del alcance funcional verificado contra código. |
| [`ProblemStatement.md`](ProblemStatement.md) | El problema que resuelve el producto. |
| [`TargetUsers.md`](TargetUsers.md) | Usuarios objetivo (PyMEs multi-usuario, roles internos, Platform Super Admin). |
| [`UserPersonas.md`](UserPersonas.md) | Personas construidas a partir del catálogo de permisos real, no de roles inventados. |
| [`UserStories.md`](UserStories.md) | Historias de usuario, cada una marcada `[BUILT]` o `[PLANNED]`. |
| [`BusinessRules.md`](BusinessRules.md) | Reglas de negocio, incluidas las de seguridad multi-tenant ya vinculantes. |
| [`OutOfScope.md`](OutOfScope.md) | Qué está genuinamente fuera de alcance vs. planeado pero no construido. |
| [`SuccessMetrics.md`](SuccessMetrics.md) | Qué se debería medir — sin instrumentación activa todavía. |

Ver también: [`../00_VISION/`](../00_VISION/) (visión y estrategia) y [`../02_REQUIREMENTS/`](../02_REQUIREMENTS/) (requisitos detallados que derivan de este PRD).
